# Falancé v0.8.0-beta.1 — Public Beta

**Tanggal:** 25 Agustus 2026  
**Branch:** `beta-release`  
**Model:** Free limited access  
**Production source of truth:** Google Sheets

## Ringkasan

Falancé v0.8.0-beta.1 adalah rilis Public Beta untuk memvalidasi pengalaman inti pencatatan dan pemantauan keuangan keluarga Indonesia. Rilis ini menggunakan branch `beta-release` dan deployment beta terpisah; Production utama tetap menggunakan Google Sheets dan tidak mengalami cutover ke Supabase.

## Yang tersedia

- Mini App Falancé dengan halaman Beranda, Transaksi, Laporan, dan Akun.
- Tambah, edit, dan void transaksi dengan authorization server-side serta family isolation.
- Category summary, cash-flow analytics, category filter, dan drill-down pada Laporan.
- AI text parser dalam bentuk draft yang selalu membutuhkan review/approval.
- CSV export untuk OWNER/ADMIN menggunakan dialog download native Telegram `WebApp.downloadFile`.
- Badge Public Beta, metadata versi runtime, status tester berbasis family, dan CTA feedback Telegram dengan template pesan.
- Landing page Public Beta pada `/beta`.
- Batas operasional maksimal 20 family dan maksimal 3 active member per family, dengan rollout cohort 5 → 10 → 15 → 20.

## Fitur yang dikunci selama beta

- Receipt Vision/scan struk dinonaktifkan untuk seluruh beta. Pengujiannya ditunda sampai deployment Production beta yang telah disetujui karena webhook Telegram bersifat global per bot.
- Print Preview disembunyikan dari UI dan endpoint server menolak akses beta.
- PDF export disembunyikan dari UI dan endpoint server menolak akses beta.
- Budget planner, planned transactions, recurring liabilities, PWA/offline, Mini App receipt upload, serta benefit final beta tester belum termasuk rilis ini.

## Catatan beta tester

Family baru yang dibuat ketika Public Beta aktif memperoleh entitlement registry `BETA` dan dapat ditampilkan sebagai `Founder Beta Tester`. Family yang telah ada sebelum beta tidak otomatis memperoleh status tersebut. Benefit komersial masa depan belum dijanjikan; tidak ada komitmen lifetime-free.

## Acceptance

CSV export telah diuji melalui Telegram Mini App dengan akun OWNER/ADMIN. Dialog native muncul, tidak membuka external browser atau safe-browsing tab, file tersimpan, dan isi file tervalidasi sebagai CSV laporan transaksi. Client Telegram yang tidak menyediakan `WebApp.downloadFile` menggunakan fallback fail-closed dengan menyembunyikan tombol CSV.

Quality gate sebelum rilis mencakup `npm test`, `npm run lint`, `npm run build`, dan `git diff --check`. Supabase tetap migration-ready untuk kebutuhan pasca-launch; kredensial service-role tidak digunakan sebagai backend Production pada rilis ini.

## Batasan dan monitoring

Operator harus menghentikan onboarding family baru bila muncul pola Google Sheets `429`, endpoint `5xx`, repeated `unable to load`, authorization failure non-session, lonjakan latency, atau indikasi data isolation failure. Registry pusat perlu dibackup dan diperiksa menggunakan `npm run check:registry` sesuai runbook sebelum perubahan operasional besar.
